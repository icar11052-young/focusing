Focusing 0.1.0-beta.1 — 클릭한 창을 크게

Windows 10/11 64비트용 시험 배포본입니다.
AutoHotkey를 따로 설치하지 않아도 됩니다.

시작하기
1. Focusing을 실행합니다. 창 대신 작업 표시줄의 트레이 아이콘으로 동작합니다.
2. 같은 모니터에 작업 창 두 개를 나란히 놓습니다.
3. 작은 창의 제목 표시줄을 클릭하거나 Ctrl을 누른 채 창 안을 클릭합니다.
4. 청록색 막대를 드래그해 비율을 조절합니다.
5. 막대를 더블클릭하면 두 창의 좌우 위치가 바뀝니다.

단축키
- Ctrl+Alt+F12: 켜기/끄기
- Win+Alt+Shift+1: 왼쪽 크게
- Win+Alt+Shift+2: 오른쪽 크게
- Win+Alt+Shift+S: 좌우 교환
- Win+Alt+Shift+T: 클릭 방식 순환

설치형
설치 프로그램을 실행해 설치합니다. 관리자 권한은 기본적으로 필요 없습니다.
로그인 시 자동 실행과 바탕 화면 바로가기는 설치 중 선택할 수 있습니다.
삭제는 Windows 설정의 설치된 앱에서 Focusing 제거를 선택합니다.
사용자 설정은 %APPDATA%\Focusing\focusing.ini에 저장하고, 제거 후에도 보존합니다.

무설치형
ZIP 전체를 쓰기 가능한 폴더에 풀고 Focusing.exe를 실행합니다.
함께 든 portable.flag가 있으면 설정을 같은 폴더의 Data에 저장합니다.
다른 PC로 옮길 때 폴더 전체를 복사하면 설정도 함께 옮겨집니다.
종료 후 무설치 폴더를 지우면 제거됩니다. 자동 실행 등록은 하지 않습니다.

관리자 권한 앱
관리자 권한 터미널 등과 함께 쓸 때는 트레이의 관리자 권한 재시작을 선택하세요.
권한 요청을 취소해도 기존 실행은 유지됩니다.

주의할 점
- 기존 개인용 포커싱 스크립트와 배포본을 동시에 실행하지 마세요.
- 이 시험 배포본은 코드 서명이 없어 Windows 다운로드/실행 경고가 나타날 수 있습니다.
- 각 앱의 최소 너비, 사용자 정의 제목 표시줄, 혼합 화면 배율에 따라 동작이 달라질 수 있습니다.
- 네트워크 연결, 계정, 결제, 사용 통계 전송 기능은 없습니다.
- 다른 PC에서 설치·기본 클릭·드래그·재시작·제거를 확인한 뒤 넓게 배포하는 것을 권장합니다.

제3자 구성요소
AutoHotkey 2.0.26 런타임을 포함합니다. 라이선스와 대응 소스는 licenses 폴더를 참조하세요.
설치 프로그램은 Inno Setup으로 제작했습니다.
