# Mac용 포커싱

macOS14 이상 · Apple Silicon·Intel universal 베타.

## 설치

DMG를 열고 Focusing.app을 Applications에 옮긴 뒤 실행합니다. 유료 개발자 서명·Apple 공증이 없는 베타라 macOS가 차단할 수 있습니다. 출처를 확인한 후 시스템 설정 → 개인정보 보호 및 보안에서 해당 앱의 실행 허용 여부를 직접 결정하세요. 회사 관리 정책이 차단하면 관리자에게 문의하세요.

시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 Focusing을 허용하고 앱을 다시 실행하세요.

## 사용

같은 화면에 두 창을 나란히 놓고 작은 창의 빈 제목줄 또는 Control+클릭으로 확대합니다. 메뉴 막대 ◧에서 좌우 확대·교환·원래 배치 복원·확대 일시정지·종료를 선택합니다. 청록색 막대를 끌면 비율이 바뀌며 더블클릭하면 좌우 위치가 바뀝니다. 로그인 시 자동 실행은 메뉴에서 선택합니다.

| 단축키 | 동작 |
|---|---|
| Control+Option+F12 | 확대 일시정지·재개 |
| Command+Option+Shift+1 / 2 | 왼쪽 / 오른쪽 크게 |
| Command+Option+Shift+S | 좌우 교환 |
| Command+Option+Shift+T | 클릭 방식 변경 |

웨일은 상단 탭 옆 빈 곳과 오른쪽 위 고래 장식 영역을 지원합니다. 탭·버튼·웹 본문은 자동 확대하지 않습니다. 앱의 접근성 구조에 따라 빈 제목줄을 인식하지 못하면 Control+클릭을 사용하세요.

‘첫 클릭 바로 동작 (지원 앱)’은 기본 꺼짐입니다. 켜면 웨일·Chrome·ChatGPT/Codex·Antigravity의 비활성 창을 먼저 활성화한 뒤 원래 클릭을 전달합니다. 확대 일시정지와 별개로 켜고 끕니다. 문제가 생기면 이 메뉴만 끄세요.

## 설정·검증·삭제

설정 도메인은 com.young.focusing.mac이며 회전 로그는 ~/Library/Logs/Focusing.log에 저장됩니다. 이벤트 역할·창 좌표·프로세스 번호와 배치 성공 여부를 기록하며 문서·웹 본문은 수집하지 않습니다. 네트워크·계정·사용 통계 전송은 없습니다.

개발 Mac에서 시험 창21개 검사·배치 계산10개 및 실제 웨일 고래 영역과 확대 유지의 사용자 확인을 수행했습니다. Intel은 교차 빌드·구조 확인만 했으며 실제 Intel Mac 시험은 하지 않았습니다. 모든 앱·화면 조합을 검증한 것은 아닙니다. 최소 창 크기와 전체화면·다른 창 배치 도구 등에 따라 동작이 제한됩니다.

삭제는 로그인 자동 실행을 끄고 앱을 종료한 뒤 휴지통으로 옮깁니다. 개인 개발판과 동시 실행하지 마세요. 개발판의 외부 LaunchAgent는 공개 앱이 관리하지 않습니다.
